# Aus dem Laufzeitsatz entfernte Grafiken

Diese Dateien wurden beim Grafik-Audit vom 9. September 2026 aus
`src/assets/medieval` verschoben. Sie bleiben als nachvollziehbare Rohquellen
erhalten, werden von Vite aber nicht mehr in das Spielpaket aufgenommen.

- `buildings/house`: beschriftete, schmale Atlas-Spalten mit Rahmenresten
- `buildings/farm`: dieselben Atlasfehler; ein Motiv ist zudem eine Mühle
- `buildings/harbor`: vier Varianten mit fest eingebrannter Wasserfläche und
  ohne vollständige Richtungsabdeckung
- `trees`: unvollständige Kiefernkronen ohne verlässlichen Stammfuß
- `shore`: perspektivische Vollkacheln, die nicht als drehbare Kliffkante
  funktionieren

Die aktiven Ersatzdateien stehen im Manifest. Diese Ablage ist kein
Kandidatenordner: Inhalte hier nur als Referenz für Herkunft oder Fehlerbilder
verwenden.
